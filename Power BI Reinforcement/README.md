# Car Price Analysis - Power BI Dashboard

## Project Overview
This project analyzes car pricing data using Power BI to identify market trends, vehicle value factors, and pricing patterns across different brands and models.

## Features
- Interactive car price visualization
- Brand comparison analysis
- Feature impact on pricing
- Market trend identification
- Geographical price variations

## Dataset
The dataset contains information about various car specifications, prices, brands, and market data.

## Power BI Reports
- `car_price_analysis.pbix` - Main Power BI dashboard file
- Data cleaning and transformation steps documented
- Interactive filters and visualizations

## Usage
1. Open `car_price_analysis.pbix` in Power BI Desktop
2. Refresh data connection if needed
3. Use interactive filters to explore different segments
4. Analyze price trends and patterns

## Requirements
- Power BI Desktop (free download)
- Microsoft Excel or compatible data source
- Basic understanding of data analysis concepts
